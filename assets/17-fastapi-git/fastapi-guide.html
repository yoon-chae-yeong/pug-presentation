REST API: GET과 POST의 차이

GET: 가져오기 (엽서)

  • • 주소창에 데이터가 보임 (엽서처럼 공개)
  • • Request Body를 쓰지 않음
  • • 검색, 단순 페이지 이동, 정보 조회에 사용

POST: 제출하기 (봉투)

  • • 데이터가 봉투(Body) 안에 숨겨짐 (보안성)
  • • Request Body에 큰 JSON 데이터를 담음
  • • 글쓰기, 결제, LLM 채팅 프롬프트 전송에 사용

중요: 두 비유는 데이터의 '시각적 노출 차이'를 설명하기 위함입니다. API 요청 시에는 GET과 POST 중 하나만 선택하여 사용하며, POST가 GET을 '포함'하지 않습니다.

FastAPI란 무엇인가

FastAPI는 파이썬(Python)으로 웹 API를 만들기 위한 현대적이고 아주 빠른 웹 프레임워크입니다.

REST API와의 결정적 차이

REST API가 통신을 위한 약속이자 '설계 방식(건축 도면)'이라면, FastAPI는 그 설계를 바탕으로 실제 집을 아주 쉽고 빠르게 지어주는 '최신식 공구세트(엔진)'입니다.

  • Interactive API 문서 자동 생성
  • 파이썬 생태계에서 가장 빠른 프레임워크
4

FastAPI 코드 구조 이해

from fastapi import FastAPI  # [1] 설계도(클래스) 가져오기

app = FastAPI() # [2] 인스턴스: 설계도에서 찍어낸 진짜 실체(서버 객체)

@app.post("/api/chat") # [3] 데코레이터: 길(Path)과 방식(Method)을 연결
async def chat(request: ChatRequest): # [4] 비동기 함수: 실제 처리 로직
    result = await call_llm(request.prompt)
    return {"answer": result} # [5] 리턴: 브라우저로 보낼 결과 (자동 JSON 변환)

인스턴스(Instance)

FastAPI라는 틀에서 찍어낸 '진짜 실체'입니다. 이 `app`이 실제로 메모리에 올라가서 요청을 기다립니다.

데코레이터(Decorator)

함수 위에 `@`를 붙여 기능을 덧씌웁니다. "이 함수는 특정 주소와 연결해!"라고 지정하는 역할입니다.

HTTP 응답(Response)의 구성 요소

Status Code (상태 코드)

200 OK 요청 성공!
400 Bad Request 클라이언트 요청 오류
404 Not Found 경로를 찾을 수 없음
422 Unprocessable 데이터 검증(Pydantic) 실패
500 Internal Error 서버측 로직 오류

Response Body (응답 본문)

서버가 사용자에게 돌려주는 실제 JSON 데이터입니다.

{
  "status": "success",
  "answer": "안녕하세요!",
  "usage": { "total_tokens": 128 }
}

Pydantic의 핵심 역할

타입 검증
주요 파이썬 자료형
int정수형 (1, 10, -5)
str문자열 ("안녕")
float실수형 (3.14)
bool논리형 (True/False)
list목록 ([1, 2, 3])
dict사전 ({"key": "val"})

입력값이 `int`, `str`, 'list' 등과 일치하는지 체크합니다.

자동 형변환

`"100"`이 들어와도 숫자로 정의되어 있으면 `100`으로 변환해 줍니다.

기본값 설정

값이 없을 때 미리 정해둔 기본값을 자동으로 할당합니다.

필수/옵션 구분

`...`을 사용해 필수 필드를 지정하거나 선택적 필드를 구분합니다.

객체 변환

JSON 데이터를 다루기 쉬운 파이썬 객체로 자유롭게 변환합니다.

에러 자동 생성

검증 실패 시 구체적인 JSON 에러 메시지를 만들어 줍니다.

from pydantic import BaseModel, Field # 라이브러리 임포트

class ChatRequest(BaseModel):
    prompt: str = Field(..., min_length=2) # 필수 & 최소 2자
    temperature: float = Field(default=0.7) # 선택 & 기본값 0.7

BaseModel은 Pydantic 라이브러리의 핵심으로, 파이썬 객체에 '데이터 검증(Validation)'과 '타입 힌트(Type Hinting)' 능력을 부여하는 역할을 합니다.
